# Homebrew Tap for CursorPulse

Official Homebrew tap for [CursorPulse](https://github.com/hieuduy1751/cursor-pulse) — Ambient AI Agent Cursor Companion & State Tracker for macOS.

## Installation

```bash
brew install --cask hieuduy1751/tap/cursor-pulse
```

Or:

```bash
brew tap hieuduy1751/tap
brew install --cask cursor-pulse
```
